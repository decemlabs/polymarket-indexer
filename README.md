# Polymarket Indexer

Он-чейн индексатор сделок и балансов кошелька в Polymarket напрямую через Polygon RPC и Tortoise ORM (SQLite / PostgreSQL).

---

## Установка и быстрый старт

Требуется Python >= 3.14 и менеджер пакетов [uv](https://github.com/astral-sh/uv). Дополнительные сервисы и Docker не нужны.

```bash
# 1. Установка зависимостей
uv sync

# 2. Настройка кошелька по умолчанию (опционально)
cp .env.example .env
```

Параметры в `.env`:
- `WALLET` — целевой кошелек по умолчанию (например `0x46b353667fd7d846af3bbeda6584b0e5b883d3de`)
- `DATABASE_URL` — строка подключения к БД (по умолчанию `sqlite://polymarket.db`, поддерживается `postgres://...`)
- `POLYGON_RPC_URLS` — список архивных RPC-нод через запятую
- `SCANNER_CONCURRENCY` — количество параллельных воркеров сканера (по умолчанию `2`)
- `CHUNK_SIZE` — базовый размер пачки блоков при сканировании (по умолчанию `15000`)
- `NORMALIZER_CONCURRENCY` — количество воркеров параллельной нормализации (по умолчанию `4`)
- `NORMALIZER_CHUNK_SIZE` — размер пачки блоков при нормализации (по умолчанию `50000`)

> **Входные данные — только адрес кошелька.**
> Начальный блок активности кошелька определяется автоматически за ~2 секунды бинарным поиском через RPC. Сканирование и нормализация выполняются параллельно с динамической балансировкой между RPC-нодами и непрерывным (gap-free) сохранением чекпоинтов.

## Полный справочник команд CLI

Адрес кошелька можно передавать аргументом в любую команду: `uv run polymarket-indexer <команда> [АДРЕС]` (если адрес не указан, берется значение `WALLET` из `.env`).

### 1. `status` — просмотр балансов и статистики
Отображает текущий статус индексации: чекпоинт, отставание от верхушки сети, сводку по сохраненным сырым логам, операциям, активным позициям в локальной БД и он-чейн балансы долларового обеспечения (`pUSD` / `USDC.e`).

```bash
# Для кошелька из .env:
uv run polymarket-indexer status

# Для конкретного адреса:
uv run polymarket-indexer status 0x46B353667FD7d846AF3BbEdA6584B0E5B883d3De
```

---

### 2. `scan` — историческое сканирование он-чейн событий
Параллельно выкачивает все связанные с кошельком логи (`raw_logs`) из блокчейна Polygon через RPC-ноды. Автоматически распределяет нагрузку, дробит чанки при превышении лимитов RPC и после завершения запускает нормализацию.

```bash
uv run polymarket-indexer scan [АДРЕС] [ОПЦИИ]
```

**Опции:**
- `-c`, `--concurrency INT` — количество параллельных воркеров (по умолчанию `2` или из `.env`).
- `--chunk-size INT` — размер пачки блоков на один запрос (по умолчанию `15000`).
- `--from-block INT` — принудительный стартовый блок (по умолчанию берется с сохраненного чекпоинта или находится автодетектом).
- `--to-block INT` — конечный целевой блок (по умолчанию `latest` — текущая верхушка сети).
- `--chunks INT` — ограничить число чанков (удобно для быстрого тестирования).
- `--no-normalize` — пропустить шаг нормализации после сканирования.

**Примеры:**
```bash
# Досканировать новые блоки до верхушки сети:
uv run polymarket-indexer scan

# Сканирование с 3 параллельными потоками и чанком в 20,000 блоков:
uv run polymarket-indexer scan -c 3 --chunk-size 20000

# Сканировать конкретный диапазон блоков:
uv run polymarket-indexer scan --from-block 90000000 --to-block 91000000

# Тестовый прогон: скачать только 5 чанков без нормализации:
uv run polymarket-indexer scan --chunks 5 -c 2 --no-normalize

# Сканировать произвольный кошелек:
uv run polymarket-indexer scan 0x46B353667FD7d846AF3BbEdA6584B0E5B883d3De
```

### 3. `normalize` — параллельная нормализация логов в балансы
Преобразует сырые события (`raw_logs`) в проводки (`balance_changes`: BUY, SELL, SPLIT, MERGE, REDEEM, WRAP, UNWRAP, TRANSFER) и формирует актуальные остатки портфеля (`current_balances`).

```bash
uv run polymarket-indexer normalize [АДРЕС] [ОПЦИИ]
```

**Опции:**
- `-c`, `--concurrency INT` — количество параллельных воркеров нормализации (по умолчанию `4`).
- `--chunk-size INT` — диапазон блоков в одной пачке (по умолчанию `50000`).

**Примеры:**
```bash
# Нормализовать все накопившиеся сырые логи:
uv run polymarket-indexer normalize

# Нормализация в 8 параллельных потоков чанками по 100,000 блоков:
uv run polymarket-indexer normalize -c 8 --chunk-size 100000

# Нормализация для конкретного кошелька:
uv run polymarket-indexer normalize 0x46B353667FD7d846AF3BbEdA6584B0E5B883d3De
```

---

### 4. `verify` — он-чейн сверка рассчитанных балансов
Сверяет рассчитанные локальные остатки из базы данных напрямую со смарт-контрактами в блокчейне (`balanceOf` для ERC-20 `pUSD`/`USDC.e` и ERC-1155 `CTF`).

```bash
uv run polymarket-indexer verify [АДРЕС] [ОПЦИИ]
```

**Опции:**
- `--limit INT` — количество крупнейших позиций для сверки (по умолчанию `20`).
- `--all` — сверить абсолютно все активные позиции кошелька.
- `--block INT` — номер блока, на состояние которого делать срез (по умолчанию последний чекпоинт).

**Примеры:**
```bash
# Быстрая сверка топ-20 позиций и долларового остатка:
uv run polymarket-indexer verify

# Сверка топ-5 позиций:
uv run polymarket-indexer verify --limit 5

# Полная сверка всех позиций кошелька:
uv run polymarket-indexer verify --all

# Сверка состояния на конкретном историческом блоке:
uv run polymarket-indexer verify --block 93700000
```

---

### 5. `live` — синхронизация в реальном времени
Запускает непрерывный процесс демона: слушает появление новых блоков в сети Polygon, скачивает транзакции кошелька, нормализует их и моментально обновляет балансы.

```bash
uv run polymarket-indexer live [АДРЕС] [ОПЦИИ]
```

**Опции:**
- `--interval FLOAT` — интервал опроса ноды в секундах (по умолчанию `3.0`).

**Примеры:**
```bash
# Запуск постоянного мониторинга:
uv run polymarket-indexer live

# Мониторинг с опросом каждые 2 секунды:
uv run polymarket-indexer live --interval 2.0
```
